🔐 Password Change API Test

Note: You can use either phone number OR customer ID to identify the user. Both fields are optional but at least one is required.

API Documentation

Endpoint: POST /api/change_password.php

Parameters (Form Data):

  • phone - Phone number (optional if customer_id provided)
  • customer_id - Customer ID (optional if phone provided)
  • current_password - Current password (required)
  • new_password - New password (required, min 4 characters)

Success Response:

{
  "success": true,
  "message": "Password changed successfully",
  "customer_id": 123,
  "phone": "07501234567"
}

Error Response:

{
  "success": false,
  "error": "Error message here"
}

Example cURL:

curl -X POST https://veloxshoppingiq.com/api/change_password.php \
  -d "phone=07501234567" \
  -d "current_password=oldpass123" \
  -d "new_password=newpass456"
