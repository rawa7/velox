CUSTOMER STATEMENT API - USAGE GUIDE
====================================

ENDPOINT: /api/customer_statement.php
METHOD: GET

DESCRIPTION:
This API provides comprehensive customer account statement data including:
- Customer details
- Financial summary (balance, payments, completed purchases)
- Pending items (orders not yet completed)
- Completed items (sold/delivered items - status -2)
- Refunded items (status -3)
- Payment history
- Status breakdown

PARAMETERS:
-----------
1. customer_id (required) - The ID of the customer
2. date_from (optional) - Filter from this date (format: YYYY-MM-DD)
3. date_to (optional) - Filter to this date (format: YYYY-MM-DD)

IMPORTANT NOTES:
----------------
- Balance calculation: ONLY completed items (status = -2) are counted in balance
- Balance = Total Completed Items Value - Total Payments
- Pending items are shown separately and NOT included in balance calculation
- Refunded items (status = -3) are also excluded from balance
- Positive balance = Customer owes money (Due)
- Negative balance = Customer has credit (Overpaid)
- Zero balance = Account is settled

EXAMPLES:
---------

1. GET FULL STATEMENT (NO DATE FILTER):
   curl "https://veloxshoppingiq.com/api/customer_statement.php?customer_id=853"

2. GET STATEMENT WITH DATE RANGE:
   curl "https://veloxshoppingiq.com/api/customer_statement.php?customer_id=853&date_from=2025-01-01&date_to=2025-10-18"

3. GET STATEMENT FROM SPECIFIC DATE:
   curl "https://veloxshoppingiq.com/api/customer_statement.php?customer_id=853&date_from=2025-09-01"

BALANCE STATUS VALUES:
----------------------
- "due" - Customer owes money (positive balance)
- "overpaid" - Customer has credit (negative balance)
- "settled" - Account is balanced (zero balance)

ERROR RESPONSES:
----------------
1. Missing customer_id:
   Status: 401
   {
     "success": false,
     "message": "Customer ID is required. Please provide customer_id in request."
   }

2. Customer not found:
   Status: 404
   {
     "success": false,
     "message": "Customer not found."
   }

3. Database error:
   Status: 500
   {
     "success": false,
     "message": "Database error occurred: [error details]"
   }
