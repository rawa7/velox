HOW TO USE:
═══════════

ADMIN PANEL (Web Interface):
→ http://veloxshoppingiq.com/api/notification_panel.php

FLUTTER API:
→ GET: http://veloxshoppingiq.com/api/notifications.php?customer_id=X
→ PUT: Mark as read
→ POST: Create notification

SEND BULK NOTIFICATIONS:
→ curl -X POST http://veloxshoppingiq.com/api/notification_center.php \
    -H "Content-Type: application/json" \
    -d '{"action":"notify_by_status","status_id":2}'
